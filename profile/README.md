# ContextCache

**Project memory for teams that work with AI, with receipts.**
Capture the decisions and findings from your AI sessions once. Recall them in any tool, with every answer cited back to the memory it came from.

## What it does

- **Capture** decisions and findings from ChatGPT, Claude, Gemini and coding agents: browser extension, MCP, CLI, or the web app. Previews before anything is saved; secrets are redacted on the way in.
- **Curate** in an Inbox: raw captures become typed memory cards you approve, edit, or reject. Nothing is stored silently.
- **Recall** anywhere: a hybrid engine (full-text, vector, recency, forgetting curve) returns a context pack to paste, or your AI reads it natively over MCP. Answers cite memory ids, and every memory carries its provenance.
- **Govern**: audit chain, retention, and erasure by design. Captured content never trains models.
